## 演習

- 第1回（素のLLM）とエージェントの回答の違い：素のLLMは、宿題の「3レベル」を「基礎・応用・発展」と回答したが、エージェントは用語集を検索して、正しい「基礎・実装・発展」と回答した。エージェントはツールを使って講座固有の情報を確認できるため、回答の正確性が高まることが分かった。
- `--trace` で見えたツール呼び出し（ツール名と引数）：LoRAとQLoRAの違いは？ と質問したところ、search_glossary が2回呼び出された。引数はそれぞれ {"query": "LoRA"} と {"query": "QLoRA"} だった。エージェントが2つの用語を調べてから回答していることが分かった。
- 1つの質問での LLM 呼び出し回数（`requests`）：LoRAとQLoRAの違いは？ という質問では、requests=2 だった。1回目にLLMがツールの使用を判断し、ツールの実行結果を受け取った後、2回目に回答を生成した。ツール呼び出し回数（tool_calls）も2回だった。
- 追加したツールと、docstring に書いた説明：make_quiz(lecture: int) を app/tools.py に追加した。指定した回の用語集からランダムに1つ選び、確認問題と答えを返すツールである。docstring には、復習用の問題を求められたときに使うことや、指定した回の用語から問題を作ることを記載した。app/agent.py に登録し、「第2回の確認問題を出して」と質問して動作を確認した。

## 宿題

- 取り組んだレベル：実装
- やったこと：app/tools.py に save_learning_log を作成し、学習記録を learning_log/learning_log.md に追記できるようにした。app/agent.py では requires_approval=True を設定し、保存前にタイトルと内容を表示して、利用者が y（承認）または n（拒否）を選べるようにした。承認・拒否の結果は DeferredToolResults を使ってエージェントに渡し、処理を再開するようにした。
- 結果：save_learning_log をエージェントに登録し、保存前に利用者の確認を求める動作を確認できた。n（拒否）を入力した場合はファイルが作成されず、y（承認）を入力した場合は learning_log/learning_log.md に学習記録が正しく保存された。cat コマンドで保存内容も確認した。また、uv run pytest -q を実行した結果、15件のテストがすべて成功した。
- 気づき・疑問：AIエージェントは、ツールを登録するだけでなく、実行結果に応じた処理も必要だと分かった。特に、ファイルへの保存のような操作では、requires_approval=True を設定し、利用者の承認を得てから実行することが重要だと学んだ。また、Pydantic AIのクラスの読み込み先や output_type の設定が原因でエラーが発生したが、エラーメッセージを確認しながら修正することで、プログラムの仕組みを理解できた。
